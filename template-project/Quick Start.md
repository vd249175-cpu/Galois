# 🏁 Quick Start Guide

Ready to write some notes? Follow these steps:

### 1. Create a New Document
* In the Left Sidebar panel, click the **+ (New Note)** icon in the header.
* Type a name for your note, and hit Enter. The note is created and immediately opened.

### 2. Connect Your Notes
* Type double brackets around a note's name to link it, e.g. `[[Welcome]]`.
* When clicked in the rendered preview, it will navigate to that document.

### 3. Switch Projects
* Click the **Folder (Switch Notebook)** icon in the left sidebar header to load any other folder on your computer.

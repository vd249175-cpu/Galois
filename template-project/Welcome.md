# 📓 Welcome to DNOTE Notebooks

Welcome to your brand-new minimalist markdown note-taking environment!

DNOTE allows you to open any system folder as a notebook workspace and connect thoughts using interactive WikiLinks.

![DNOTE Logo](media/logo.jpg)

### 🚀 Getting Started
Explore the template project by clicking on these connected notes:
* Learn about our interactive [[Features]]
* Follow the [[Quick Start]] guide to write your first note

Your notes are rendered live as nodes in the **Graph View** panel on the right. Try dragging the nodes around to see the spring physics simulation in action!

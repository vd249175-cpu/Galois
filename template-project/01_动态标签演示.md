# DNOTE 标签与动态计算系统

在 DNOTE 中，标签不仅仅是静态的文本分类，而是支持三级递进逻辑的智能数据索引。

### 1. 静态普通标签
通过在文档的任何位置键入以 `#` 开头的单词，系统会自动在文件树和图谱中为您建立索引：
* 例如，本段落底部写有：`#演示 #标签 #指南`

### 2. 动态正则标签
系统支持根据正则表达式提取特定格式的文本作为标签，消除了人工添加标签的繁琐工作。

### 3. 动态脚本计算标签
这是最强大的功能！通过在文档中引入脚本触发声明（例如本行下方的特殊指令），DNOTE 会在文件保存时，后台自动执行指定的 Python 脚本进行标签评估：

`run:tag_calculator.py`

> [!IMPORTANT]
> 检查左侧栏**文件树**中本文件下方的标签，除了静态标签外，您应该能看到由 Python 脚本 `script/tag_calculator.py` 计算并自动注入的：`#AI推荐`、`#系统运算`、`#高频标签`。

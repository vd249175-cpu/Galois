# DNOTE 标签与动态计算系统

在 DNOTE 中，标签不仅仅是静态的文本分类，而是支持三级递进逻辑的智能数据索引。

### 1. 静态普通标签
通过在文档的 YAML frontmatter 区域直接添加带有斜杠 `/` 分隔的分级标签（例如 `DNOTE/标签/普通标签`），系统会自动在左侧栏和关系图谱中为您建立起层级分明的分类目录和树状拓扑关系。

### 2. 动态正则标签
系统支持根据正则表达式从文档正文中提取特定格式的文本作为标签。
- 比如我们在前言中配置的 `re:#([a-zA-Z0-9_\/]+)`，它会自动检索本文件 Body 部分中任何以 `#` 开头且包含斜杠 `/` 的分级词汇。
- 例如，Body 尾部写有：`#DNOTE/标签/正则提取 #DNOTE/核心特性 #DNOTE/文档`，这三个词将被正则引擎自动提取为对应的层级标签。

### 3. 动态脚本计算标签
通过在 YAML tags 列表中引入特殊的脚本触发声明 `run:tag_calculator.py`，DNOTE 会在文件保存时，后台自动执行指定的 Python 脚本进行标签评估。这里我们配置其动态返回 `DNOTE/标签/脚本计算` 级数标签。

> [!IMPORTANT]
> 检查左侧栏**文件树**或右侧的**关系图谱**（Lattice Graph）：
> 在层级关系模式下，你会看到扁平的标签已经被解析为 `DNOTE` ➡️ `指引`/`标签`/`视图` ➡️ 具体的底层叶子标签的层级级数结构，并且文件节点会精准关联到它们对应的级数位置。

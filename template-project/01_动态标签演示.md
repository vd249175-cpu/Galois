# DNOTE 标签与动态计算系统

在 DNOTE 中，标签不仅仅是静态的分类文本，而是支持多维、动态评估和运行时提取的智能数据神经元。

---

## 🛠️ 三种标签声明模式

本页面的 YAML Frontmatter 声明如下，它集成了 DNOTE 完整的三维标签系统：

| 标签声明方式 | Frontmatter 声明示例 | 解析与匹配机制 |
| :--- | :--- | :--- |
| **1. 静态普通标签** | `- 普通标签` | 保存文件时同步录入。支持树状分类与直观搜索。 |
| **2. 动态正则标签** | `- re:#([\w\u4e00-\u9fa5]+)` | 运行时同步解析笔记 Body。自动提取捕获组内容作为标签。 |
| **3. 动态脚本标签** | `- run:tag_calculator.py` | 保存文件时调用 `uv run script/tag_calculator.py`。支持进行深度自定义的逻辑标签计算。 |

---

## 🔍 正则与脚本标签运行示例

### 1. 正则标签提取（Regex Tags）
我们在 Frontmatter 中配置了 `- re:#([\w\u4e00-\u9fa5]+)`。它会自动搜寻正文部分任何以 `#` 开头的单词，提取出来成为本篇笔记的有效标签。
* 📝 **提取源**：请查阅本页底部的 `#DNOTE #标签 #正则提取 #核心特性 #文档`，它们已被成功索引！

### 2. 动态脚本标签（Script Tags）
我们在 Frontmatter 中配置了 `- run:tag_calculator.py`。
DNOTE 会在后台以 `uv run` 执行位于 `script/tag_calculator.py` 中的 Python 程序，该程序接收 `DNOTE_NOTE_PATH` 环境变量，并将计算完成的动态标签数组写入 `DNOTE_OUTPUT_FILE` 指定的文件中。
* 🐍 **计算结果**：本笔记被注入了脚本返回的 `脚本计算` 和 `推荐` 标签。

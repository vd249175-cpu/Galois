# DNOTE 标签与动态计算系统

在 DNOTE 中，标签不仅仅是静态的文本分类，而是支持三级递进逻辑的智能数据索引。

### 1. 静态普通标签
通过在文档的 YAML frontmatter 区域直接添加普通词汇，系统会自动建立分类索引。

### 2. 动态正则标签
系统支持根据正则表达式提取特定格式的文本作为标签，消除了人工添加标签的繁琐工作。
- 比如我们在前言中配置的 `re:#([a-zA-Z0-9_\u4e00-\u9fa5]+)`，它会自动检索本文件 Body 部分中任何以 `#` 开头的中文/英文词汇，将其索引为标签。
- 例如，Body 尾部写有：`#教程 #核心特性 #文档`，这三个词将被正则引擎自动识别并提取为系统标签。

### 3. 动态脚本计算标签
这是最强大的功能！通过在 YAML tags 列表中引入特殊的脚本触发声明 `run:tag_calculator.py`，DNOTE 会在文件保存时，后台自动执行指定的 Python 脚本进行标签评估。

> [!IMPORTANT]
> 检查左侧栏**文件树**中本文件下方的标签，除了静态标签外，您应该能看到由 Python 脚本 `script/tag_calculator.py` 计算并自动注入的：`#AI推荐`、`#系统运算`、`#高频标签`。
> 并且由正则匹配的标签 `#教程`、`#核心特性`、`#文档` 也应被完美列出。

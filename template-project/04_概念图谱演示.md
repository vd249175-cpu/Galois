# DNOTE 知识图谱与概念格（Lattice）

DNOTE 的关系图谱不是普通的"标签云"或"链接图"——它基于**形式概念分析（Formal Concept Analysis, FCA）**自动推导出笔记之间的层级关系。

### 1. 图谱的核心逻辑：集合包含

每篇笔记的标签集合构成一个"节点"，当 A 的标签集合是 B 的**真子集**时，图谱自动从 A 向 B 连一条边：

```
A.tags ⊊ B.tags  →  A → B
```

例如，本项目中：

- `00_新手指引` 拥有标签 `{DNOTE, 指引, 新手指引, 视图, 分栏}`
- `01_动态标签演示` 拥有标签 `{DNOTE, 指引, 标签演示, 标签, ...}`
- 两者都含 `{DNOTE, 指引}`，系统会自动归并并推导出包含关系

### 2. 两种展示模式

点击图谱右上角的 **"⬡ 虚节点"** 按钮可切换：

| 模式 | 节点 | 说明 |
|------|------|------|
| 关闭 | 仅真实笔记 | 图谱只显示有实体文件的节点 |
| 开启 | 笔记 + FCA 虚节点 | 额外生成多标签枢纽节点，展示跨笔记的共同概念 |

### 3. 虚节点是什么？

当多篇笔记共享某些标签，但没有一篇笔记专门代表那个"交集"时，图谱会自动生成一个**虚节点**：

```
本项目所有指引类文件都含 {DNOTE, 指引}
→ 自动生成虚节点 #DNOTE+指引（若无对应笔记）
→ 连接所有包含该标签集合的笔记
```

虚节点以**胶囊形**区别于普通笔记节点（圆形）。

### 4. 传递归约：最少的边，最全的信息

图谱会自动去除"冗余边"（可以通过中间节点推导出的边），只保留**直接覆盖关系**，确保图谱既完整又简洁。

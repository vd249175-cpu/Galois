# 如何在 DNOTE 中写一篇总结型笔记

总结型笔记是知识管理中最有价值的笔记类型之一——它不是原始记录，而是**经过消化后的提炼**。在 DNOTE 中，总结型笔记拥有特定的结构惯例，使其能被图谱和标签系统最大化利用。

---

## 标准结构模板

```markdown
---
tags:
  - 主题分类       ← 大类标签（对应图谱高层节点）
  - 具体子主题     ← 细分标签（图谱中层节点）
  - 总结           ← 标记为总结类文档
  - 来源标注       ← 可选：书名、课程名、项目名
---
# 标题：一句话说清楚这篇笔记的核心结论

> 一句话摘要：把这篇笔记最核心的洞察写在这里。

## 背景 / 问题
写清楚"为什么要研究这个"，方便未来的自己快速定位场景。

## 核心要点
用最少的字，传递最多的信息。

- **要点 A**：解释
- **要点 B**：解释
- **要点 C**：解释

## 思考与延伸
- 这和 [[其他笔记]] 有什么关联？
- 有什么反直觉的地方？
- 还有什么没搞清楚？→ [[TODO_待研究]]

## 来源 / 参考
- 原始资料链接或文件路径
```

---

## 为什么这个结构有效？

### 标签设计让图谱自动归类

标签从**大类 → 小类**排列，DNOTE 的 Lattice 图谱会自动将这篇总结归入对应的知识层级。例如：

```
tags: [知识管理, 总结, 写作技巧]
```

图谱会自动发现：
- 本文与所有含 `知识管理` 标签的笔记同属一个集群
- 如果有另一篇 `[知识管理, 总结, 卡片盒]`，两者会共享一个 `#知识管理+总结` 虚节点

### 双向链接让知识网络生长

在"思考与延伸"区域用 `[[笔记名]]` 主动建立链接，DNOTE 会在被引用笔记的**反向链接面板**中记录本文，形成双向可导航的知识图。

### 一句话摘要是为未来的自己写的

六个月后看到这篇笔记，你未必记得内容。摘要是快速判断"这篇是不是我要找的那个"的钥匙。

---

## 💡 你可以直接试试

1. 在左侧文件树点击 **+** 新建一篇笔记
2. 粘贴上方模板
3. 填写 YAML 标签后保存（`Cmd+S`）
4. 打开右侧**关系图谱**，观察这篇新笔记出现在哪个位置

# Galois 自定义快捷键与脚本指令

在 Galois 中，你可以自由配置快捷键或通过斜线 `/` 指令，一键运行本地的 Python 脚本。这使你可以完成诸如字数统计、知识库自动索引、甚至外部文件构建等各种强大的定制任务。

---

## ⚙️ 项目指令注册表 (`command/commands.json`)

由于后台脚本指令执行时不需要在 Markdown 中插入文本，为了避免混淆，**我们已在底层将此类脚本命令从斜线 `/` 自动补全菜单中隐藏过滤**。它们仅通过**全局快捷键**或**窗口右侧动作栏**进行静默触发：

| 指令 ID | 显示名称 | 快捷键 | 后台执行命令 | 作用域与触发方式 |
| :--- | :--- | :--- | :--- | :--- |
| `project.runStats` | **统计项目字数** | `Cmd+Shift+T` | `uv run script/note_stats.py` | 聚焦编辑器时按快捷键触发 |
| `project.buildIndex` | **重建标签索引报告** | `Cmd+Shift+L` | `uv run script/build_index.py` | 聚焦编辑器时按快捷键触发 |
| `project.exportSummary` | **导出并更新知识库概览报告** | `Cmd+Shift+E` | `uv run script/export_summary.py` | 聚焦编辑器时按快捷键触发 |

> [!NOTE]
> 相对地，输入斜线 `/` 唤起的菜单现在被专一化定位为：**插入文本片段与动态反应式小部件**（它们带有 `content` 属性而非 `script`，见下一章描述）。

## 🌐 环境变量上下文传递

当 Galois 触发执行你的脚本时，会自动向子进程注入丰富的**上下文环境变量**。你的 Python 脚本可以通过读取这些变量，感知用户的编辑位置和状态：

```python
import os

project_path  = os.environ.get('DNOTE_PROJECT_PATH')  # 当前笔记项目根目录绝对路径
active_file   = os.environ.get('DNOTE_ACTIVE_FILE')   # 当前编辑器正聚焦的文件绝对路径
output_file   = os.environ.get('DNOTE_OUTPUT_FILE')   # Galois 缓存输出文件的约定路径
cursor_line   = os.environ.get('DNOTE_CURSOR_LINE')   # 光标当前所在行号 (0-indexed)
cursor_col    = os.environ.get('DNOTE_CURSOR_COL')    # 光标当前所在列号 (0-indexed)
selected_text = os.environ.get('DNOTE_SELECTED_TEXT')  # 编辑器中当前选中的高亮文本片段
```

Galois 要求脚本将运行结果以 JSON 格式（包含 `status`, `message` 和 `data`）写入 `DNOTE_OUTPUT_FILE` 指定的路径。执行完毕后，主程序会自动读取并弹出通知或渲染状态栏！

## 🎯 交互体验：现在就试一试吧！

### 体验一：运行项目字数统计
1. 确保当前编辑器处于聚焦状态（在本文中点击任意位置）。
2. 按下快捷键 `Cmd+Shift+T`（或 Windows 上的 `Ctrl+Shift+T`），或者在任意空白行输入 `/` 并选择“**统计项目字数**”。
3. **效果**：编辑器底部状态栏将展示由 `script/note_stats.py` 动态返回的笔记篇数和总字符数。

### 体验二：导出并生成知识库概览报告
1. 在文本编辑器内按下快捷键 `Cmd+Shift+E`（或 Windows 上的 `Ctrl+Shift+E`）。
2. **效果**：系统会调度 `script/export_summary.py`，遍历本项目中的所有笔记进行复杂解析，并在根目录下动态生成一份 `知识库概览报告.md`！你可以打开左侧文件树，发现新生成的文件，并在编辑器中浏览这份漂亮的图表报告。

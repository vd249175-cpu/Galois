# DNOTE 自定义快捷键与脚本指令

在 DNOTE 中，你可以通过配置快捷键绑定，一键触发本地的 Python 脚本，以实现对笔记库的深度分析、自动重构或集成外部工具。

### 1. 快捷键配置 (`command/commands.json`)
本模板项目已经为您配置了一个统计当前笔记库文件和字数的指令，其配置文件位于 `command/commands.json` 中：
* **快捷键绑定**：`meta+shift+t`（Mac 上为 `Cmd+Shift+T`，Windows 上为 `Ctrl+Shift+T`）
* **触发指令**：`project.runStats`
* **执行脚本**：`uv run script/note_stats.py`

### 2. 脚本接收的上下文环境变量
当 DNOTE 触发快捷键执行脚本时，会自动向 Python 进程注入一系列富上下文环境变量，供脚本读取：
* `DNOTE_PROJECT_PATH` — 当前打开的笔记项目根目录绝对路径
* `DNOTE_ACTIVE_FILE` — 当前正在编辑的笔记文件的绝对路径
* `DNOTE_OUTPUT_FILE` — 约定的 JSON 格式输出缓存文件路径（本指令输出在 `.dnote_cache/project.runStats.json`）
* `DNOTE_CURSOR_LINE` / `DNOTE_CURSOR_COL` — 触发指令时编辑器光标的行列位置
* `DNOTE_SELECTED_TEXT` — 触发指令时选中的文本片段

### 3. 🎯 交互体验：现在就试一试吧！
1. 确保当前编辑器处于焦点状态（点击本页面文本任意处）。
2. 按下快捷键 `Cmd+Shift+T`（或 `Ctrl+Shift+T`）。
3. 观察编辑器底部状态栏提示，以及弹出的提示窗口，它展示了通过 `script/note_stats.py` 统计的笔记文件数 and 总字符数。

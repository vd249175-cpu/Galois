# ✨ Features of DNOTE

Here is what makes DNOTE a premium, minimalist environment:

### 1. Dual Editing Modes
* Press `meta+e` (Cmd+E on Mac, Ctrl+E on Windows) or click the **Preview/Edit** button in the header toolbar to switch formats.
* Edit raw markdown source code in unrendered mode, or view rendered headings, bolding, italics, quotes, checklists, and linked images in live preview.

### 2. Interactive Graph View
* All internal [[WikiLinks]] automatically form connections.
* View a live force-directed link chart in the right panel.
* Double-click a node in the graph to quickly jump to that document in the editor.

### 3. Drag and Drop Auto-Archiving
* Simply drag any image, audio, or video file from your computer and drop it directly onto the editor.
* DNOTE copies the asset into the `media/` directory and embeds the appropriate reference inline.

# DNOTE 智能双向链接笔记

欢迎使用 **DNOTE**！这是一个面向未来的极简、高交互性双向链接知识库。

本项目本身就是 DNOTE 的功能演示与交互指南，请按顺序点击以下双向链接，开启你的功能探索：

* 💡 [[01_动态标签演示]] — 学习如何在笔记中使用静态、正则以及 Python 脚本动态计算出的标签。
* ⌨️ [[02_脚本指令演示]] — 体验如何通过自定义快捷键触发本地 Python 脚本来深度分析你的笔记。
* 🖥️ [[03_实时状态与终端]] — 了解 DNOTE 是如何与外部原生终端、`agy` CLI 进行数据同步并发布实时状态的。

---

> [!TIP]
> **新手指引：如何探索本项目？**
> 1. **分割视窗**：按下 `Cmd+D` 可以将当前页面水平分栏，按下 `Cmd+W` 关闭当前聚焦的面板。
> 2. **调整主题**：点击右侧栏下方的齿轮按钮 ⚙️，可在设置中一键将系统外观由默认的**温暖米色**切换至**深空极夜**。

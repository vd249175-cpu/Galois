# ⚡ 立即执行与单次渲染脚本

DNOTE 除了支持每隔数秒的轮询执行外，还支持在 Markdown 被**打开**或**保存**时，立即单次执行一次 Python 脚本。这非常适合用于获取某些不需要频繁刷新的数据快照（例如：外部编译时间、API 静态配置、网络连接状态快照等）。

---

## 🎯 反应式单次执行（Reactive Single-Run）

在占位符中，只要**不配置 `& interval=N` 周期参数**，DNOTE 便会将其识别为单次渲染脚本：

> **⚡ 反应式快照小部件**：
> * **执行状态**：{{ script/run_once_demo.json:status | run="run_once_demo.py" }}
> * **快照时刻**：{{ script/run_once_demo.json:timestamp }}

### ⚙️ 声明机制
上述部件在正文中的占位符声明如下：
`{{ script/run_once_demo.json:status | run="run_once_demo.py" }}`

### 💡 交互体验：
1. 编辑并保存当前文件（`Cmd+S`）。
2. **效果**：上方的 `快照时刻` 会**立即更新为当前的保存时间**。并且它不会像上一章的 CPU 占用率那样每 3 秒自动刷新，而是仅在您**保存文件**或**重新切换打开此笔记**时，被编辑器的解析钩子立即执行一次。


---

## 🏷️ YAML Frontmatter 动态脚本标签

另一种“保存时立即执行”的钩子是 YAML 中的标签脚本（`run:` 前缀标签）：

```yaml
---
tags:
  - run:tag_calculator.py
---
```

每当本笔记被保存时，DNOTE 的标签解析引擎都会在后台立即通过 `uv run` 调用指定脚本，计算出该笔记的动态标签（例如本笔记在 [01_动态标签演示] 中演示的脚本计算流程），无缝实现自底向上的标签网络维护。

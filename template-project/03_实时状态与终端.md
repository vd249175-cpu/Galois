# Galois 实时状态同步与终端集成

Galois 采用了仿生反射链路设计。编辑器并非孤立的静态排版界面，它会将你的操作状态实时同步给外部脚本、终端工具，并支持在笔记中直接嵌入反应式动态变量。

---
爱哭的飞机

## 🐍 1. 反应式动态状态绑定（Reactive expressions）

Galois 支持在 Markdown 文本中使用特殊的 `{{ }}` 占位符声明动态表达式。编辑器会自动周期性调度后台 Python 脚本，读取生成的 JSON 文件并局部更新渲染视图。

> [!TIP]
> **👇 以下小部件正在实时工作！你可以移动光标或修改正文，观察它们的变化：**
> 
> * **系统监控状态**：{{ script/sys_monitor.json:status | run="sys_monitor.py" & interval=3 }}
> * **CPU 使用率**：{{ script/sys_monitor.json:cpu }} | **内存使用率**：{{ script/sys_monitor.json:memory }} *(每 3 秒自动执行 sys_monitor.py)*
> * **数据最后更新**：{{ script/sys_monitor.json:timestamp }}
> 
> ---
> 
> * **项目守护进程状态**：{{ script/on_project_run.json:status | interval=1 }}
> * **守护进程 PID**：{{ script/on_project_run.json:pid }} | **常驻运行时间**：{{ script/on_project_run.json:uptime }} *(每 1 秒读取一次)*
> * **守护进程最近心跳**：{{ script/on_project_run.json:last_active }}
> 
> * **📁 【实时】正在编辑文件**：{{ script/on_project_run.json:live_typing.active_file_name }}
> * **📍 【实时】当前光标行**：第 {{ script/on_project_run.json:live_typing.current_line_num }} 行
> * **📏 【实时】当前行字符数**：{{ script/on_project_run.json:live_typing.current_line_length }} 字
> * **✨ 【实时】选区字符数**：{{ script/on_project_run.json:live_typing.selected_char_count }} 字
> * **🛡️ 【实时】状态自检**：{{ script/on_project_run.json:live_typing.todo_status }}

* **初次绑定声明**：`{{ script/sys_monitor.json:cpu | run="sys_monitor.py" & interval=3 }}` 表示当打开此文档时，每 3 秒调度运行一次 `sys_monitor.py` 并提取 `cpu` 字段展示。
* **无干扰读取**：后续的 `{{ script/sys_monitor.json:memory }}` 占位符不需要再重复声明 `run=` 属性，它们会自动共享同一个 JSON 数据源，保持界面清爽。
* **纯文件轮询**：`{{ script/on_project_run.json:status | interval=2 }}` 不带 `run` 属性，表示它不会重复调度新的进程，而是每 2 秒轮询读取已由外部常驻进程更新的 JSON 文件，实现极其高效的解耦通信。

> [!TIP]
> **🚀 快捷插入：你不需要手动打出这些复杂的 `{{ }}` 语法！**
> 我们已经在项目的 [commands.json](command/commands.json) 中配置了对应的“自定义插入字符串”。你现在只需在新行中输入 `/`，就会在自动提示菜单中看到：
> 1. **插入系统实时监控小部件** — 选中可直接插入 CPU 与内存监控组件。
> 2. **插入项目生命周期守护进程状态** — 选中可直接插入常驻守护进程的复现组件。

## 🧭 2. 实时运行态坐标轴 (`.dnote_runtime.json`)

当你在编辑器中移动光标、选中文本或切换聚焦的文件时，Galois 会在项目根目录下实时写入 `.dnote_runtime.json`。这相当于笔记项目的“感觉神经元”：

* `activeFile` — 当前正聚焦的笔记文件绝对路径
* `cursor.line` / `cursor.column` — 实时光标行列坐标（0-indexed）
* `cursor.selectedText` — 实时选中的高亮文本片段
* `timestamp` — 上一次发生交互变化的时间戳

你可以通过外部命令行，或者在底部的**内置终端**（Terminal 区域）中运行监测工具来实时感知编辑器的动态：
```bash
# 在终端中实时监控光标位置
tail -f .dnote_runtime.json
```

## 🔄 3. 项目生命周期脚本 (Lifecycle Hooks)

Galois 为笔记项目定义了三个与打开、运行、关闭周期强绑定的全局 Python 脚本钩子，统一存放在 `script/` 目录下：

```
       [ 打开笔记本文件夹 ]
                │
                ▼
      on_project_open.py  (同步阻塞，用于环境检查或创建缓存)
                │
                ▼
       on_project_run.py   (后台常驻守护进程，不阻塞 UI，可提供云同步等服务)
                │
         [ 正常编辑笔记... ]
                │
      (切换项目 或 退出 Galois)
                │
                ▼
      on_project_close.py (同步阻塞运行，安全落盘，并销毁 on_project_run.py 后台进程)
```

> [!IMPORTANT]
> 切换项目或正常关闭 Galois 时，主程序会调用 `script/on_project_close.py`，用于最终状态写入和后台进程清理。脚本必须保持快速、可重入，并自行管理 PID 或停止标记；强制杀进程、断电等情况不能由生命周期钩子保证。
